Sistema de Gestión de tickets

Hola! Este proyecto es una aplicación web interactiva diseñada para poder gestionar tickets sobre incidencias de todo tipo. 
La plataforma optimiza los flujos de trabajo de los equipos de soporte técnico, permitiendo que haya comunicación entre los usuarios y los resolutores del área de TI.

---
 Características Principales

El sistema simula un entorno operativo real mediante el manejo del ciclo de vida completo de un ticket:

*   Gestión Dinámica de Estados: Los tickets cambian su flujo de trabajo en tiempo real a través de estados normalizados (Abierto, en progreso, cerrado).
*   Matriz de Priorización: Clasificación inteligente de incidencias (Alta, Media, Baja) para garantizar el cumplimiento de los tiempos de respuesta según la criticidad del problema.
*   Arquitectura Semántica: Construido con buenas prácticas de accesibilidad web (SEO), utilizando etiquetas estructurales estándar de HTML5 (como `<main>`, `<section>`, `<footer>`).
*   Interfaz: Diseño fluido optimizado para pantallas de escritorio y notebooks
---
Tecnologías Utilizadas

| Componente | Tecnología | Uso Principal |
| :--- | :--- | :--- |
| **Frontend** | HTML5 | Estructura semántica de la aplicación y maquetado de formularios. |
| **Estilos** | CSS3 | Diseño de la interfaz de usuario, grillas, paneles y diseño responsive. |
| **Lógica** | JavaScript | Manejo de eventos del DOM, validación de campos y control de estados de los tickets. |
